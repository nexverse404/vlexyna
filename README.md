# Vlexyna — music video studio

Turn a track and a picture into an audio-reactive music video, in the browser, and render it to a real MP4. Nothing is uploaded — analysis, preview and export all run locally.

Built around one reference look (the *Fantasize* style): anime background breathing with the bass, a shutter reveal, floating bokeh, a diagonal lens flare, kick-locked camera shake, a spectrum, and a song badge with your logo.

## Quick start

```bash
npm install
npm run dev      # http://localhost:5173
```

Then:

1. **Drop a track** anywhere on the page (MP3/WAV/FLAC/M4A). Vlexyna analyzes it — tempo, onsets, beat grid, band energies, the drop.
2. **Drop an image or video** for the background (or use the demo artwork).
3. Tweak in the side panels — every slider moves the live preview immediately.
4. **Export video** → frame-exact MP4 (H.264 + AAC) via WebCodecs. Safari/Firefox fall back to a realtime WebM capture; Chrome/Edge give you MP4.

No track handy? Hit **Try the demo** — a synthesized 126 BPM track in A♯ minor (see `tools/make-demo-track.py`) plus demo artwork.

## What the analyzer does

- 2048-point FFT at 60 fps → 6 band energies (sub…air) with adaptive normalization
- spectral-flux onset detection with an adaptive threshold → the hits
- onset autocorrelation with parabolic refinement → tempo + beat grid (comb-aligned phase)
- slow RMS envelope → drop detection (the "hold back, then let go" moment)

Everything downstream is a pure function of `(t, features)` — the export renders exactly what the preview showed.

## The editor

- **Style presets** — Fantasize, Deep Aqua, Sunset Drive, Neon Club, Midnight Mono — plus a *Surprise me* dice roll
- **Direct manipulation** — grab the badge, spectrum or lens flare right on the preview and drag it
- **Undo/redo** — `Ctrl/Cmd+Z`, `Ctrl/Cmd+Shift+Z` (one step per tweak, drags collapse into one)
- **Hit echo** — feedback trails that pump with the hits
- **Project save/open** — settings as a `.json` file (media stays local)
- **Poster export** — any frame as a full-resolution PNG
- **Shortcuts** — `Space` play/pause · `←/→` frame step (`Shift` = 5 s) · `Home/End` · `L` loop · double-click the preview to play
- Badge auto-hide, spectrum peak caps, flare angle/ghosts, particle wind/twinkle, rotation shake, zoom release — all live

## Project layout

```

test/          analysis pipeline test (synthetic 126 BPM track)
tools/         demo track synthesizer
public/demo/   demo track + artwork
```
